How ShuttleDraw works

A configurable badminton doubles tournament manager. Run any number of pairs across one or more groups — the 10-pair, 2-group, 3-court setup is just the default example. Everything runs in the browser — no server, no accounts.

Tournament configuration

  • The pair list is the source of truth — add, remove, rename or move pairs at any time
  • The group split is read from actual membership (e.g. 4 + 4 or 5 + 4), never fixed
  • Fixtures are generated automatically from the real groups

Group stage

  • Round-robin inside each group — every pair plays every other pair once
  • A group of N pairs produces N × (N − 1) / 2 matches (4 → 6, 5 → 10, 6 → 15)
  • Single game to 21. Win = 2 points, loss = 0. No draws.
  • Standard badminton scoring: win by 2 clear points, with a 30-point cap (21–20 → play on; 30–29 wins)
  • Ranked by points, then point difference, then points scored

Rolling court scheduling

  • No fixed time slots — a court picks up the next eligible match the moment it frees up
  • Each court has its own editable availability window (Settings → Court configuration)
  • A match already running always finishes, even past its court's closing time
  • Teams waiting longest are prioritised; back-to-back matches are avoided where possible
  • A team can never be on two courts at once

Knockout

  • You choose how many pairs qualify from each group (Settings → Qualification)
  • The bracket is built from the number of qualifiers: 4 → SF + Final, 8 → QF onward, 16 → Round of 16 onward
  • Rounds are best of 3; if the qualifier count is not a power of two, byes advance teams without a fake match

Data

  • Saved to browser localStorage — refresh-safe
  • Export a JSON backup any time from Settings; import it on another device
